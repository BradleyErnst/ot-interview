# OpenText Partner + Solutions Scraper

> Open output.json to see the sample results immediately.

## Project Description

This Node.js project scrapes the OpenText Partner Directory and Partner Solutions Catalog to produce a clean JSON file listing partners and the solutions they provide. It demonstrates the ability to handle JavaScript-rendered pages using Puppeteer, join data from multiple sources, and produce structured output suitable for analysis or reporting.
